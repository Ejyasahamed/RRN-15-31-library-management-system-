# 📚 Easy Library
### University Library Management System

A full-featured digital library web application built with React.js

---

## 🚀 Features
- 🔐 Student & Admin login portal
- 🏠 Student dashboard with reading progress
- 🔍 Search books by title, author, or ISBN
- 📖 Book issue & return system
- ❤️ Wishlist / bookmark books
- 🛠️ Admin panel — catalog, users, maintenance
